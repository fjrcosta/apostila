Introdução a Variáveis Aleatórias

Do resultado do experimento ao número real

1. Motivação

Ao realizar um experimento aleatório, frequentemente interessa mais uma função do resultado do que o próprio resultado:

  • A soma das faces de dois dados, não a combinação particular que a gerou.
  • O número de caras em três lançamentos de uma moeda, não a sequência.
  • O número de chamadas numa central telefônica, a vida útil de uma lâmpada, o número de veículos num pedágio.

2. Espaço de Probabilidade (Ω, 𝓕, P)

  • Ω: espaço amostral, todos os resultados possíveis do experimento.
  • 𝓕: σ-álgebra, a coleção de subconjuntos de Ω (os eventos) aos quais podemos atribuir probabilidade.
  • P: medida de probabilidade, que atribui a cada evento de 𝓕 um número em [0, 1].

3. Definição Formal

Uma variável aleatória X é uma função mensurável que associa cada ω ∈ Ω a um número real:

X : (Ω, 𝓕) → (ℝ, 𝓑(ℝ))

𝓑(ℝ) é a σ-álgebra de Borel: a menor σ-álgebra que contém todos os intervalos de ℝ.

Mensurabilidade

Para todo boreliano B ∈ 𝓑(ℝ), a pré-imagem deve ser um evento:

X⁻¹(B) = { ω ∈ Ω : X(ω) ∈ B } ∈ 𝓕

É isso que garante que P(X ≤ x) ou P(a < X ≤ b) estejam bem definidas.

Três gestações, X = número de meninos: X(FFF) = 0, X(FFM) = 1, …, X(MMM) = 3, logo ℝX = {0, 1, 2, 3}.

4. Discretas e Contínuas

  • Discreta: valores num conjunto finito ou infinito enumerável, como {0, 1, 2, …}. Ex.: número de acidentes numa semana, casos de uma doença num mês.
  • Contínua: valores num intervalo de ℝ, como [a, b] ou [0, ∞). Ex.: peso, altura, tempo de vida de uma lâmpada, temperatura.

5. Função Massa de Probabilidade (PMF)

Para X discreta, associa a cada valor xi sua probabilidade:

f(xi) = P(X = xi)

Condições necessárias:

  1. Intervalo: 0 ≤ f(xi) ≤ 1 para todo xi ∈ ℝX.
  2. Evento certo: Σ f(xi) = 1.

Exemplo: número de caras em dois lançamentos

6. Função de Distribuição Acumulada (CDF)

F(x) = P(X ≤ x)

Propriedades:

  • 0 ≤ F(x) ≤ 1.
  • F é não decrescente: x ≤ y ⇒ F(x) ≤ F(y).
  • lim F(x) = 0 quando x → −∞ e lim F(x) = 1 quando x → +∞.

Caso discreto

F(x) é a soma das probabilidades dos valores u ≤ x, e tem forma de escada. Cada salto é a própria PMF:

F(x) = Σu ≤ x f(u)   e   f(x) = F(x) − F(x⁻)

No exemplo das duas moedas: F(x) = 0 para x < 0; 1/4 em [0, 1); 3/4 em [1, 2); 1 para x ≥ 2.

7. Função Densidade de Probabilidade (PDF)

Quando o espaço amostral tem infinitos pontos, a probabilidade de qualquer valor isolado tende a zero:

P(X = x) = 0  (X contínua)

Por isso a densidade f(x) não dá probabilidades pontuais: a probabilidade é a área sob a curva num intervalo. Condições:

  1. f(x) ≥ 0 para todo x.
  2. ∫−∞∞ f(x) dx = 1.
P(a < X < b) = ∫ab f(x) dx

Para X contínua, F(x) é uma curva crescente e contínua de 0 a 1.

f(x) = 2x em [0, 1]: área total = 1 (triângulo de base 1 e altura 2) e P(0 ≤ X ≤ 1/2) = (1/2 · 1)/2 = 1/4.

8. Esperança e Variância: Caso Discreto

E(X) = Σ xi · P(X = xi)
Var(X) = Σ [xi − E(X)]² · P(X = xi) = E(X²) − [E(X)]²

Propriedades da esperança

  • E(c) = c;  E(cX) = c · E(X);  E(X ± c) = E(X) ± c.
  • E(X ± Y) = E(X) ± E(Y).
  • Se X e Y são independentes: E(XY) = E(X) · E(Y).

Propriedades da variância

  • Var(c) = 0;  Var(cX) = c² · Var(X).
  • Independentes: Var(X ± Y) = Var(X) + Var(Y).
  • Quaisquer: Var(X ± Y) = Var(X) + Var(Y) ± 2 Cov(X, Y), com Cov(X, Y) = E(XY) − E(X)E(Y).
Face de um dado: E(X) = 3,5 e Var(X) = 35/12 ≈ 2,92.

9. Esperança e Variância: Caso Contínuo

As somas dão lugar a integrais:

E(X) = ∫−∞∞ x · f(x) dx
Var(X) = ∫−∞∞ [x − E(X)]² · f(x) dx

Exemplo: distribuição uniforme

Dureza de uma peça de aço, X ~ U(50, 70), com f(x) = 1/20 em [50, 70]:

  • E(X) = (50 + 70)/2 = 60.
  • Var(X) = (70 − 50)²/12 ≈ 33,33.
  • P(55 ≤ X ≤ 60) = (60 − 55) · 1/20 = 0,25.
